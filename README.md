# Debugga Landing

Landing statica per `debugga.it`, realizzata con Astro.

## Sviluppo

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Il build finale viene generato in `dist/`.

## Deploy

Il workflow di GitHub Actions pubblica `dist/` su GitHub Pages quando c'è un push su `main`.
