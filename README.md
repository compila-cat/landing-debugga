# Compila Landing

Landing estàtica per a `compila.cat`, feta amb Astro.

## Desenvolupament

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

El build final es genera a `dist/`.

## Desplegament

El workflow de GitHub Actions publica `dist/` a GitHub Pages quan hi ha push a `main`.
